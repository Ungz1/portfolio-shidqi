# Portofolio Interaktif Muhammad Shidqi Fadhlurrahman

Portofolio web modern, interaktif, dan responsif dengan tema **Dark Aurora Glow & Glassmorphism** (terinspirasi dari video TikTok referensi).

## ✨ Fitur Unggulan
- **Ambient Aurora Animation:** Latar belakang gradasi neon dinamis bergerak halus.
- **Table of Contents Interaktif:** Kartu menu daftar isi bernomor (01–06) dengan *smooth scroll* langsung ke section yang dipilih.
- **Lightbox Dokumen & Sertifikat:** Foto kegiatan & sertifikat resmi (Bapenda, Bank Muamalat, Bank Mandiri Taspen, Disnaker) bisa diklik untuk di-zoom/perbesar dalam modal.
- **Aksi Kontak Cepat:** Tombol langsung menuju chat WhatsApp, email, dan unduh CV PDF asli.
- **3D Card Hover:** Efek interaktif perspektif 3D mengikuti kursor mouse pada foto profil hero.
- **Responsif:** Tampilan optimal di semua ukuran layar (Laptop, Tablet, Smartphone).

## 🚀 Cara Menjalankan
1. **Cara Cepat:**
   - Cukup klik dua kali file `Buka_Portofolio.bat` di folder `C:\SHIDQI\`.
2. **Lewat Terminal / Node.js:**
   ```bash
   cd C:\SHIDQI\portfolio-app
   npm start
   ```
   Lalu buka browser di: `http://localhost:3000`

## 🌐 Cara Online-kan Secara Gratis (Bila Ingin Link Publik)
Folder `public/` berisi file web statis murni (`index.html`, `style.css`, `script.js`, dan `assets/`). Anda bisa mengunggah folder ini secara gratis ke:
